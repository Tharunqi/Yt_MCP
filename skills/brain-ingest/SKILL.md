# Brain ingest

1. Read [[brain/tharun/resources/second-brain-workflow]] and open the index in your contributor folder (for example, [[brain/tharun/index]]).
2. Add unsorted information to your `brain/<contributor>/inbox/`; put useful, organized notes in that contributor's PARA folders.
3. Write a short summary in your own words. Keep source, date, requirement IDs, and issue/PR links when known.
4. Link related notes with `[[wikilinks]]`. Do not guess missing facts or IDs.
5. Add significant runs to the contributor's own `brain/<name>/log.md` and update that folder's `index.md` if a new note should be easy to find.
6. Never add credentials, tokens, or secrets.
