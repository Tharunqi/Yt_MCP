# Brain query

1. Start at the index in your contributor folder (for example, [[brain/tharun/index]]) and read [[brain/tharun/resources/second-brain-workflow]].
2. Search relevant project, area, resource, and person notes.
3. Answer from those notes; link the supporting notes and requirement IDs.
4. Say when a fact or issue/PR link is missing instead of guessing.
5. When drafting an ADR or skill, cite at least one distilled note.
6. Add the result to the right PARA folder and update that contributor's `brain/<name>/index.md` when the user asks to keep it.
