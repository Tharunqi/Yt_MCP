# brain-refine

Use this workflow when inbox material needs sorting or existing notes need cleanup.

1. Start at [[brain/index]], read [[second-brain-workflow]], and review `brain/inbox/`.
2. Move useful material into `projects/`, `areas/`, `resources/`, or `archive/` according to PARA actionability.
3. Search for existing notes before creating duplicates. Merge overlaps while preserving source references, requirement IDs, decisions, and contributor attribution.
4. Repair Obsidian wikilinks and confirm each resolves to a note or heading. Add issue/PR links when they exist; do not invent identifiers.
5. Update [[brain/index]] when adding or moving an entry point. Keep `brain/log.md` at one entry per commit and consolidate intermediate checkpoints.
6. Preserve each contributor's authorship; do not write another person's personal note on their behalf.
7. Follow [[second-brain-conventions]] for PARA and PR requirements and [[youtube-mcp-requirements]] for product constraints.

Brain changes go through a reviewed PR. Keep secrets out of notes and logs.
