# Brain refine

1. Read [[second-brain-workflow]] and review items in `brain/inbox/`.
2. Move each useful note into `projects/`, `areas/`, or `resources/`; move inactive notes to `archive/`.
3. Merge duplicates carefully and keep the original source or date when useful.
4. Fix `[[wikilinks]]`, requirement IDs, and issue/PR links. Do not invent issue or PR IDs.
5. Update [[index]] and [[log]] after meaningful changes.
6. Keep notes short and plain. Never add credentials, tokens, or secrets.
