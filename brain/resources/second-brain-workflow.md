## Distilled rules

- Use PARA: inbox, projects, areas, resources, and archive.
- Start from [[index]] and keep significant run records in [[log]].
- Link notes with wikilinks. Add requirement IDs and issue/PR links when known.
- Write a short review at each stage end: what worked, what did not, and what should change.
- Every skill and ADR must cite at least one distilled note.
- Brain changes go through a pull request. Each team member writes their own notes.
- Do not put credentials, tokens, or secrets in Brain notes.
